Cek bebas — pilih akun sumber

Pilih akun sumber (boleh bukan akun admin), lalu ketik username target. Aplikasi menjawab: “apakah akun sumber ini sudah follow target?”

Cara kerja (hybrid): kalau akun sumber punya cookie sendiri → 1 request, jawaban pasti. Kalau tidak → daftar “following”-nya dibaca halaman demi halaman (1 halaman ≈ 24–50 orang) sampai target ketemu. Kalau halaman habis sebelum ketemu, statusnya ❔ ragu — bukan “tidak follow”. Isi cookie per akun di Pengaturan supaya ngebut.

Sesi login (opsional — 1 akun admin: Instagram / Threads / Facebook)

Login di browser kamu sendiri, export cookie (ekstensi “Get cookies.txt” / “Copy Cookies”), lalu tempel/upload di bawah. Tool tidak pernah meminta password dan cookie hanya tersimpan di database lokal ini.

Cara export cookie
  1. Login ke platformnya di Chrome/Firefox seperti biasa.
  2. Pasang ekstensi “Get cookies.txt LOCALLY” → klik → Export → simpan file .txt.
  3. Di kartu platform bawah, klik 📁 Upload cookies.txt lalu Simpan, atau tempel isi file ke kolom teks.
  4. Klik Tes sesi — kalau valid, fitur terkunci ikut kebuka. Cookie kedaluwarsa? Export ulang & simpan lagi.

Sesi per akun (opsional — supaya “Cek bebas” ngebut)

Simpan cookie milik satu akun tertentu supaya pengecekan “sudah follow belum” cukup 1 request, tanpa membaca daftar following. Isi hanya untuk akun yang sering kamu cek — tiap akun yang cookie-nya disimpan ikut berisiko kena pembatasan Instagram, jadi jangan dipasang ke semua akun tanpa alasan.
